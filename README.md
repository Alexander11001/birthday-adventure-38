# 🗺️ Операция «38»

Интерактивный сайт-поздравление с днем рождения: приключение с храмом сомнительной археологии, Хогвартсом, пиратами и черным ящиком.

## 🎮 Что внутри

- **6 экранов-уровней**: карта → храм → Хогвартс → Карибы → черный ящик → торт!
- **12 загадок** со свободным вводом
- **Мини-кроссворд** на экране Хогвартса
- **Анимации**: конфetti, частицы, корабль, сундук, glitch-заголовок

## 🚀 Запуск локально

```bash
start index.html
```

Или:

```bash
npx serve .
```

## ☁️ Деплой на Cloudflare Pages

```bash
npx wrangler pages deploy . --project-name=birthday-adventure-38
```

## ✏️ Кастомизация

- **Имя и возраст**: `BIRTHDAY_PERSON` в `js/questions.js`
- **Новые вопросы**: объекты в `QUIZ_DATA` в `js/questions.js`
