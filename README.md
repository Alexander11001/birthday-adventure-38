# 🗺️ Операция «38 / 13»

Интерактивный сайт-поздравление с днём рождения: приключение в стиле **Индианы Джонса**, **Тарзана** и **Пиратов Карибского моря** — с квизами в духе **ЧГК**.

## 🎮 Что внутри

- **6 экранов-уровней**: карта → храм Инди → джунгли → море → стол знатоков → торт!
- **12+ загадок**: выбор ответа и свободный ввод
- **Мини-кроссворд** на экране Тарзана
- **Анимации**: конфetti, частицы, корабль, сундук, глitch-заголовок
- **Финал**: «38 лет мудрости + 13 лет духа приключений»

## 🚀 Запуск локально

```bash
# Просто открыть в браузере
start index.html

# Или через простой сервер
npx serve .
```

## ☁️ Деплой на Cloudflare Pages

1. Зайди на [dash.cloudflare.com](https://dash.cloudflare.com/)
2. **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
3. Выбери этот репозиторий
4. Build settings: **None** (статический сайт, без сборки)
5. Deploy!

Или через CLI:

```bash
npx wrangler pages deploy . --project-name=birthday-adventure-38
```

## ✏️ Кастомизация

- **Имя именинника**: отредактируй `index.html` → секция `#screen-final`
- **Возраст**: измени `38` в `questions.js` и `index.html`
- **Новые вопросы**: добавь объекты в `QUIZ_DATA` в `js/questions.js`
